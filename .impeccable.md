# Impeccable — Design Context

## Users
Paul (the owner) driving a personal multi-agent Chrome extension from the new-tab hub, and — increasingly — from his other machines + via async feedback. The job: a calm command center that gives an overview of what the agents are doing and lets him start something new. Power with restraint; not a dashboard of everything.

## Brand Personality
- Calm, precise, technical — a quiet command center, not a toy.
- 3 words: calm, precise, legible.
- Emotional goal: confidence — the interface should feel like it's under control, never busy.

## Aesthetic Direction
- Minimal, technical, dark-first (four themes: midnight / sunlit / neon / terminal).
- Line-art SVG icons (stroke, currentColor) — **no emoji** (Paul: "tacky").
- Modern-web guidance throughout; generous whitespace; one primary action per view.
- Anti-references: cluttered dashboards, "slop", overloaded screens that show everything at once.

## Design Principles
1. **Clarity over density** — fewer visible elements; every view has one primary action. The composer is the hero of the hub.
2. **Grid alignment** — every row/column sits on a shared grid: icon (fixed) | label+description (stacked, gap) | action (right-aligned). Names and descriptions are separate columns/lines — never run together.
3. **Consistent rhythm** — one spacing scale (4/8/12/16/24/32), one control size (36px icon buttons; mic/+/send/gear all identical), one radius scale.
4. **Generous whitespace** — calm, breathing room; sections clearly separated.
5. **Accessible + still** — WCAG-AA contrast, keyboard/focus for everything, reduced-motion respected; alignment is part of legibility.

## Component model
Every UI element is a native Web Component (MV3-CSP-safe, no eval). Atomic (buttons, switch, icon) → composite (composer, dialog) → views (hub, chat, recipes, directory, settings, gallery). The gallery (docs/) renders each in isolation + composed; the extension pages use the same components.
