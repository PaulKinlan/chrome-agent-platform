Chrome Agent Platform

What this extension sends and stores

Everything below is read from the extension's own lists, so it changes when the extension does.

Data & memory on this device

Your data stays on your device. Each agent's memory and site data are kept isolated per site, so one site can never inspect or access another site's memory or tools.

Settings, agent conversations, site permissions, and cached models remain under your control and never leave this device unless you explicitly export them.

Technical storage details
  • chrome.storage.local: Local extension preferences, active provider choices, and schedule definitions.
  • Origin-Private File System (OPFS): Isolated per-site agent memory, run logs, and task artifacts.
  • IndexedDB: Local file and folder handles granted to agents, plus token usage ledgers.
