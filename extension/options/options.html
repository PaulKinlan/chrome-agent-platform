Settings

Changes save automatically.

Providers

Choose the model the hub agent uses. Your API key is stored locally in chrome.storage — never in the bundle, logs, or receipts.

The on-device Prompt API (Gemini nano) needs no key and works offline. Demo mode runs a deterministic local model — useful for testing the loop without a provider.

Agents

Multiple agents When off, the hub is a single agent. When on, the hub fans out to per-site sub-agents.

Enroll a site

Grant host access to a single origin so its WebMCP tools can be discovered. This requests the exact origin — no broad <all_urls> access.

WebMCP discovery

The content scripts that scan a page for WebMCP tools (declared document.modelContext.getTools() + functions explicitly opted in through window.webmcpExpose) live at content/main-world.js (page world) and content/content-script.js (isolated relay) — visible in the page's DevTools Sources once the origin is enrolled.

Diagnostics logs Emit structured [WebMCP] logs from the discovery content scripts into the page DevTools console.

Per-agent providers

Each named agent can use its own provider + model (overriding the global). Its key is stored with the agent and never shown back here.

Background agents

Agents that run quietly on a schedule (each wraps a recipe). Enable one to let it work in the background — e.g. the Sorting Hat groups your tabs by domain every 30 minutes.

Appearance

Browser control

Open, navigate, and close tabs, and capture screenshots need your explicit, scoped permission. Reading page text and listing tabs are always available.

Allow the agent to control the browser Open, navigate, and close tabs, and capture screenshots.

Allowed origins

Empty = a global (all-origins) grant.

Permissions

Every permission is optional. The hub runs with none of these; enable each capability when you need it. Each Enable button asks Chrome for just that permission.

System hooks

Every chrome.* event an agent can listen to + respond to. Deny a hook to stop the agent ever using it — the deny-list is authoritative and the agent cannot break past it. A hook also needs its optional permission before it can run.

Advanced — system prompts

The system prompt each agent runs with, layer by layer: the versioned built-in prompt, your customization, and the protected runtime policy (never editable, always applied last). The preview is the exact platform composition; every run also records a run-bound attestation of the exact provider-bound system message (digest + bytes, never content).
