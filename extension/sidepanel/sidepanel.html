Site Agents

A Site Agent is the page you're browsing, made actionable: tools the site (or the page) exposes — forms, search, checkout steps — become things your agents can use for you.

  1. Open a site above (it opens in a real tab).
  2. Its available tools appear below — nothing is shared until you run something.
  3. Direct work from the Agents tab.

Tools come from the site's WebMCP page or are inferred from the page itself.
